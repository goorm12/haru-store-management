# 하루상점 — 플랫폼 관리자 요구사항

- v1.1 / 2026-10-14
- 운영 웹 전용. [공통 정책](../common/requirements.md) 적용.

- 신고 검토, 상품 숨김·해제, 상점 제한·해제, 조치 사유·이력 관리.
- 상점 사전 개설 승인 없음. 일반 회원에게 관리자 역할 선택을 제공하지 않음.
- 기존 예약은 운영 제한으로 자동 취소하지 않으며 이행·문의 경로를 유지.
- 거래 문의·분쟁·탈퇴 요청을 검토하며 판매자 취소를 승인하는 역할이 아님.
- 비공개 상점 문의는 작성자·판매자 전용. 관리자 열람·대행 답변 권한은 기본 부여하지 않음.
- 공지·댓글 신고·운영 삭제 상세는 후속 설계이며 임의 권한 확대 없음.
