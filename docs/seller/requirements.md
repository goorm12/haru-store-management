### 2.4 판매자 화면과 기능

| 화면 | 주요 요구사항 |
| --- | --- |
| 로그인·가입 | 판매자 계정 로그인 및 가입 |
| 운영 상점 목록 | 소유 상점 조회, 관리할 상점 선택, 새 상점 등록 |
| 상점 등록·설정 | 상점명, 주소, 연락처, 소개, 픽업 운영시간 등록·수정 |
| 운영 홈 | 선택한 상점의 오늘 픽업 건수, 상품별 준비 수량, 픽업일 경과 예약 표시 |
| 공구 상품 목록 | 작성 중·예약 예정·예약 중·접수 중단·마감·취소 상품 조회 |
| 공구 상품 등록·수정 | 상품 정보, 가격, 수량, 예약 기간, 픽업 가능일 등록·수정 |
| 공구 상세·관리 | 예약 현황 조회, 접수 중단·재개, 공구 전체 취소 |
| 예약 목록 | 픽업일·상품·상태별 조회, 예약번호·예약자 검색, 수량 합계 확인 |
| 예약 상세 | 예약자 정보, 상품·수량·금액·픽업일, 변경 이력 조회 및 사유를 입력하는 개별 예약 취소 |
| 결제·픽업 처리 | 현장 결제 기록, 픽업 완료·미수령 처리, 사유·이력을 남기는 오기록 정정 |

상점이 하나면 로그인 후 해당 운영 홈으로 이동한다. 여러 개면 마지막으로 관리한 상점을 열고 상단에서 전환한다. 상품 등록·예약 처리 화면에는 현재 상점 이름을 항상 표시한다.



## 공지·문의

상점별 공지 작성·수정·삭제, 댓글 확인·본인 답글 작성·수정·삭제, 비공개 문의 조회·본인 답변 작성·수정·삭제. 새 문의 알림을 받고, 공지 등록 시 저장 구매자 전체·문의 답변 시 작성자에게 알린다. 판매자 당일 개별 취소는 관리자 승인 없이 즉시 처리한다.

## 프로젝트 적용 범위

이 문서는 `haru-store-management`의 판매자 반응형 웹 구현 기준이다. 회원·인증·예약 정책과 서버 검증은 [공통 기능 규칙](../common/functional-rules.md)을 따른다. 같은 계정이 두 역할을 가질 수 있지만 화면 진입과 서버 권한 검증은 역할별로 구분한다.
